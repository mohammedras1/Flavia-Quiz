# Flavia-Quiz

Ein pinkes, animiertes Freundinnen-Quiz mit 20 Runden.

## Lokal starten

```bash
python3 -m http.server 4173
```

Die Seite ist anschließend unter <http://localhost:4173> erreichbar.

## Veröffentlichung

Die App wird über GitHub Pages veröffentlicht. Nach einem Push auf `main` läuft der
Workflow `.github/workflows/deploy-pages.yml` automatisch.
